## 🌑 About The Game

**Shadow Ball** is a Python-based arcade game built using **Pygame**.

The goal is simple but challenging:

> **Control the ball, avoid obstacles, survive as long as possible, and achieve the highest score!**

As the game progresses, the difficulty can increase, testing the player's **reaction speed, timing, and focus**.
